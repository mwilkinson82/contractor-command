## Pages and access

- Members open the record with their session: `mcp_submittal_record_get` and `mcp_submittal_record_stamp` (full or super; contract-only roles are refused). Stored files are signed with the member's own session, under the existing storage policy.
- A board token that opens the submittal log opens its records: `mcp_submittal_record_open` repeats the `mcp_board_link_open` checks and logs the open with page `submittal`. The server function signs files with the service role only after the token authorized the job, the same way photos are signed.
- Sign-in return accepts the five-part record path; the token-missing check accepts the record address; the log page keeps the token on `submittal/<number>` links.
